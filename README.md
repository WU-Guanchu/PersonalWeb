# WU, Guanchu — Homepage

A compact academic personal website built for GitHub Pages.

## Publish

Create a public GitHub repository named `WU-Guanchu.github.io`, then push the
contents of this folder to its `main` branch. If the GitHub username is
`WU-Guanchu`, GitHub Pages will serve the site at
`https://WU-Guanchu.github.io/`.

Replace the `portrait-placeholder` block in `index.html` with an `<img>` element
when a portrait is available.
